The same sentence means something different depending on what has happened to the person saying it. "I'm fine" reads one way before a redundancy and another way after. ATCTM is an attempt at a model that goes back and re-reads earlier statements once it learns about a later event.

Underneath it is a seven-module BERT-based multi-task model. Two named components: a Subjective Impact Estimator, and a three-tier Temporal Event Memory that carries out that re-reading. It classifies six things from one input: event type, emotion, sentiment, sarcasm, tense, and certainty. The dataset is custom, over 490 life event types with Gen-Z context and over 49,000 annotated rows, labelled for sentiment, emotion, certainty, sarcasm, and temporal features. I built a separate synthetic dataset generator for it that emits strict JSON, 100 entries per event type, over a 17-emotion taxonomy.
