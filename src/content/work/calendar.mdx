One model, built on MVC and SOLID principles, sits behind three front ends: a command line, a headless scripting mode, and a Swing GUI.

I extended an unfamiliar codebase with recurring events and time zones without rewriting its core design.

Every change came with JUnit tests, JaCoCo coverage, and PIT mutation testing, which plants small faults in the code on purpose to confirm the tests catch them.
