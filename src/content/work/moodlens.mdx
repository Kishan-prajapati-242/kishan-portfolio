Paste in a sentence and it tells you six things about it at once: what happened, how the person feels about it, whether they mean it sincerely, whether it is past or future, and how sure they sound. A submodule of ATCTM, and the part of it you can actually try. FastAPI, Python, DeBERTa-v3, plain HTML, CSS and JavaScript, deployed on Hugging Face Spaces.

MIT licensed. The Hugging Face Space is currently in a build-error state, so the hosted demo is offline. The code and weights are in the repository.
