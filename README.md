# kishanprajapati.vercel.app

My portfolio. Projects, papers, teaching, and a page about the bugs I learned the most from.

## Running it locally

    npm install
    npm run dev

Then open localhost:4321.

## Where things live

- `src/pages` has one file per page
- `src/content/work` has the project write-ups
- `src/data` has the bits that show up in more than one place, like education, citations and availability
- `scripts` has the checks I run before shipping: layout overflow, contrast, motion, and page weight
- `public` has the resume and the favicon
